# Agora

## Description

Agora is a collaborative virtual campus platform designed to connect students and streamline campus life. Key features include:

- **Virtual Campuses**: Join custom campus environments verified by university email domains.
- **Interactive Campus Map**: Locate clubs, offices, and events using pins plotted directly on interactive campus blueprints.
- **Study & Chat Rooms**: Create or join chat rooms and temporary study sessions, complete with real-time messaging.
- **Academic Resources**: Upload, share, and request study materials, notes, and textbook chapters.
- **Tutor Marketplace**: Connect with student tutors or advertise your tutoring services for specific courses.
- **Real-Time Notifications**: Stay updated with in-app alerts and notifications.

## How to run

1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `python app.py`
